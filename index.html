SEO Técnico, Rendimiento y Seguridad Implementados

Posicionamiento en Buscadores (SEO)

100 / 100
  • • Datos Estructurados Schema.org (JSON-LD): Entidad Organization configurada con nombre oficial, sigla FENASIES, cobertura en Colombia y enlaces de referencia.
  • • Jerarquía Semántica HTML5: Uso estricto de <header>, <nav>, <main>, único <h1> dinámico, <article> y <footer>.
  • • Metaetiquetas y Open Graph: Title optimizado (68 caracteres), meta description persuasiva, URL canónica y tarjetas para compartir en redes y WhatsApp sindical.
  • • Core Web Vitals: Dimensiones explícitas (width/height) para evitar saltos de diseño (CLS = 0) y carga diferida en galería.

Parámetros de Seguridad Web (OWASP)

Blindado
  • • Sanitización Anti-XSS Activa: Función escapeHTML() aplicada a todas las entradas del buscador, filtros y editor CMS antes de renderizar en el DOM.
  • • Enlaces Externos Seguros: Todos los hipervínculos salientes incluyen rel="noopener noreferrer" para evitar secuestro de pestaña (Reverse Tabnabbing).
  • • Cabeceras Recomendadas de Producción: Configuración lista de Strict-Transport-Security (HSTS), X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff y Content-Security-Policy.
  • • Protección de Formularios: Validación estricta de tipos, límite de longitud y honeypot anti-bots en suscripción de boletines.
# Cabeceras HTTP de Seguridad (_headers / nginx.conf listas para despliegue de FENASIES):
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=()
