# Portal Web Oficial — FENASIES Colombia (Diseño Definitivo: Vanguardia Dark)

Repositorio oficial del portal web de la **Federación Nacional de Organizaciones Sindicales de Instituciones de Educación Superior (FENASIES Colombia)**, diseñado bajo los lineamientos del **Manual de Imagen Institucional Vol. 1** (Azul Profundo `#0A2E5C`, Azul Educación `#1050A0`, Amarillo Oro `#F0B010`, Azul Cian `#00A8E6` y Rojo Sindical `#E03040`).

## Estructura del Repositorio

- `index.html`: Estructura semántica HTML5, SEO Meta Tags y Schema.org JSON-LD.
- `css/styles.css`: Variables de tema, tipografías oficiales y animaciones.
- `js/app.js`: Motor dinámico de banners rotativos, 4 pestañas, filtros, buscador y CMS integrado.
- `data/site-config.json`: Archivo maestro de contenido editable sin tocar código.
- `assets/img/`: Escudo oficial FENASIES y fotografías institucionales optimizadas.
- `_headers`: Cabeceras HTTP de seguridad (CSP, HSTS, X-Frame-Options, nosniff).
- `robots.txt` y `sitemap.xml`: Archivos de indexación para motores de búsqueda.
